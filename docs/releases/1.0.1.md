towavue is an image viewer, video player and audio player for **Windows 11 x64**, by **sheeta**.

Browse media in tabs and multiple windows, follow Explorer folder order, use reading mode, edit images and video/audio ranges, and save or export your changes. Clipboard images can be pasted into new Untitled tabs. Help > About shows the application version and project links.

## Explorer integration

Supported media now appear in **Open with** and **Windows Settings > Apps > Default apps > towavue**. Select towavue through Windows to make it the default for the file types you choose. Normal file launches open fresh tabs in the last active window; **Show more options > Open in new towavue window** opens a separate window. The command-line equivalent is `towavue.exe --new-window -- "path/to/media.mp4"`.

No dedicated file icons or thumbnail provider are installed. Windows supplies the fallback file icon and thumbnails for formats supported by its installed providers, subject to Explorer settings. Existing defaults and thumbnail registrations are preserved.

## Install and update

Download **towavue-1.0.1-windows-x64-setup.exe** from this release and run it. Setup installs for the current user. If the Microsoft Visual C++ runtime is needed, its installer asks you to review its terms. Close towavue before installing manually. Windows 10 and ARM64 are not supported by this release.

The installed application checks for updates automatically; **Help > Check for updates** also starts a check. After a verified download, choose **Install now** or **Install on next launch**. Unsaved edits still receive Save / Discard / Cancel prompts. Cancelling keeps the application open. Update files are authenticated with the project's update signing key. This initial EXE and Setup do not have Windows Authenticode signatures, so Windows may display an unknown-publisher warning.

To uninstall, use Windows Settings > Apps > Installed apps. Your media and user settings are preserved. The shared Microsoft Visual C++ runtime is not removed.

## Known limits

- Codec/profile support depends on the input file. Viewing support does not guarantee lossless or animation-preserving export to every format. See the [media support notes](https://github.com/sheetau/towavue#media-support).
- HDR tone mapping is not supported.
- A tooltip in the custom file picker can sometimes interfere with row clicks after hovering.
