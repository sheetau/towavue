## Added

- English/Japanese UI with a display-language selector.
- Audio-track selection, cycling, simultaneous playback, and per-track video export choices.
- External and embedded subtitle preview with visibility and timing controls.
- Dedicated image, video and audio file icons in Explorer.

## Changed

- Sharper GPU image minification and faster Gallery/filmstrip preview loading.
- Improved seeking, timeline responsiveness and supported video export performance.
- Peak-based timeline waveforms and relative dB gain editing; separate preview speed controls.
- Refined dialogs, tabs, volume feedback and window placement restoration.
- Apache License 2.0 for towavue's code, with NOTICE included.

## Fixed

- Audio crackling caused by rounded AAC timestamps during track mixing, editing and saving.
- Inconsistent subtitle bottom spacing between normal and fullscreen views.
- Playback redraw stalls while moving or resizing windows.
- Reading-mode navigation/state inconsistencies and unintended audio-list scrolling during volume adjustment.

## Install and update

Download **towavue-1.0.2-windows-x64-setup.exe** and run it. Setup installs for the current user on **Windows 11 x64**. Close towavue before installing.
