towavue 1.0.2 brings Japanese UI, selectable audio tracks, subtitles, and improvements to media browsing, playback and editing on **Windows 11 x64**.

## Highlights

- **English and Japanese UI.** Choose the display language from View and restart when convenient.
- **Multiple audio tracks.** Select or cycle tracks, listen to all tracks together, and choose which tracks to retain when saving video. Waveforms follow the selected track; All uses the first track's waveform.
- **Subtitles.** Load external SRT/VTT/ASS and other supported subtitle files, or select embedded subtitles. Toggle visibility and adjust display timing in 0.1-second steps. Supported video exports retain embedded text tracks and retime them through edits, independently of preview settings; external and bitmap subtitles remain preview-only.
- **Smoother browsing and clearer images.** Gallery and filmstrip previews load more efficiently, reading-mode navigation is more consistent, and GPU image minification retains more detail. A fast display option remains available.
- **Improved playback and editing.** Faster seeking for eligible AAC playback, more responsive timeline dragging, shorter keyframe spacing and parallel encoding for supported video exports, and continued playback redraws while moving or resizing windows. Rounded AAC timestamps no longer introduce false gaps into track mixing, edited playback or saved video.
- **Peak waveforms and relative dB gain.** Timeline waveforms show peak amplitude with full-scale clipping. Gain edits preserve existing volume differences and support Undo. Preview playback speed is separate from saved timeline speed edits.
- **Refined Windows integration and controls.** Dedicated media file icons, restored window placement, interactive volume feedback, compact dialogs, and clearer menus and timeline controls.

## Install and update

Download **towavue-1.0.2-windows-x64-setup.exe** below. Setup installs for the current user; existing installations can update in place. Close towavue before running Setup manually. The installed app checks for updates automatically and through **Help > Check for updates** after this release is published.

Windows 11 x64 is required. EXE and Setup are not Authenticode-signed, so Windows may show an unknown-publisher warning. Automatic update metadata is signed with the existing project key. Setup requests the Microsoft Visual C++ runtime only when needed.

## Limits

- Codec/profile and export support depend on the input and output formats. See the [media support notes](https://github.com/sheetau/towavue#media-support).
- HDR tone mapping is not supported. Subtitle styles and attachments are not preserved in re-encoded exports.
- Qualification used the existing Windows 11 x64 PC. A clean PC without the VC runtime and other hardware configurations have not been tested.
