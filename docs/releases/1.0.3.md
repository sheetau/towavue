## Added

- Keyboard navigation to parent, child and sibling media folders.
- Tab speaker controls with a short fade and delayed disappearance after playback stops.

## Changed

- Redesigned Gallery and Filmstrip layouts, scrolling and keyboard navigation.
- More consistent menus, dropdowns, input placeholders and audio-list alignment.
- Refined tab volume feedback and media input behavior; removed the command grid.
- Setup now handles the required VC runtime quietly within the installer.

## Fixed

- Slow folder navigation caused by redundant media scans.
- Incorrect initial file order while Windows Shell was still sorting. Folder opening, direct file opening and Reload folder order share the same retry path; a notice explains any fallback to name order.
- Ambiguous folder-navigation errors and overly long empty-folder notices.
- Earlier status notices hiding the start of a new folder-opening operation.

## Install and update

Download **towavue-1.0.3-windows-x64-setup.exe** and run it. Setup installs for the current user on **Windows 11 x64**. Close towavue before installing.
