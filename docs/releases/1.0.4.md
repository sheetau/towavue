## Added

- Filmstrip folder breadcrumbs, navigation history, search and media filters.
- Ctrl+F focuses search in Gallery, Filmstrip or Keyboard Shortcuts. It opens Filmstrip when needed. The recent-folder picker uses Ctrl+Shift+F.
- Playback volume feedback and keyboard controls for tab volume.

## Changed

- Refined Gallery, Filmstrip, tabs, menus, tooltips and editing dialogs with consistent spacing, icons and colors.
- Preserved each tab's Filmstrip search, filter and navigation state.
- Improved image loading, folder navigation and media seek responsiveness.

## Fixed

- Filmstrip cards taking focus from search when the strip first opens or its folder listing arrives.
- Breadcrumbs briefly hiding ancestors when child-folder information arrives.
- Filmstrip covering menus, and stale context menus remaining open when switching to Filmstrip.
- Dimmed Filmstrip controls behind the command palette and inconsistent shading at popup scroll edges.

## Install and update

Download **towavue-1.0.4-windows-x64-setup.exe** and run it. Setup installs for the current user on **Windows 11 x64**. Close towavue before installing.
